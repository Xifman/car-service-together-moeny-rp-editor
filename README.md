Car Service Together Save Editor

Simple Python save editor for Car Service Together.

It automatically finds your save files and lets you change your Money and RP directly from the terminal.

Features

Automatically finds Car Service Together saves

Shows all detected saves

Shows current Money and RP

Lets you change Money, RP, or both

Creates a backup before editing

Works directly in CMD/Terminal

No extra Python packages needed

Requirements

Windows

Python 3 installed

Car Service Together installed

At least one save created in the game
